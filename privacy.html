Privacy policy

Effective 26 November 2026.

Infrastructure Backups is a personal-use application operated by its owner for their own backup and recovery needs.

Google data access and use

The application requests the Google Drive drive.file scope to create, read, update and delete backup files within the scope authorized to the application. This access is used solely for backup, retention, integrity checking and recovery. The application does not request unrestricted access to the owner's Drive.

Storage and protection

Backup data is encrypted before upload to the owner's Google Drive. Authorization credentials are stored locally on the backup system with restricted access. Google Drive stores the encrypted backup files and associated file metadata. The application does not sell Google user data, use it for advertising or share it with other users. Google Drive provides the storage service.

Retention and control

The owner controls backup retention and deletion. The owner can revoke access through their Google Account security settings and delete stored backup files from their Drive. Revoking access does not automatically delete files already stored.

Contact

For questions about this personal application, contact its owner via the application information repository. Do not post private backup data or credentials.
